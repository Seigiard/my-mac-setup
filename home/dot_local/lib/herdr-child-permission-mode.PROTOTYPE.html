Может ли read-only агент позвать родителя?

Вопрос: Можно ли при запуске запретить дочернему агенту менять файлы, но оставить ровно один автономный канал возврата, вместо наследования bypassPermissions?

Граница модели: Эта страница моделирует документированные правила CLI, а не запускает реальные процессы. Модель исходит из того, что Claude Code 2.1.236 проверяет каждую shell-подкоманду, OpenCode 1.18.30 проверяет каждую распознанную команду, а Pi 0.85.1 не умеет штатно ограничивать shell отдельными командами. Осталось проверить вживую, перекрывает ли явный режим Claude унаследованные настройки в интерактивном дочернем процессе, запущенном через Herdr.
