## Oracle

The consumer is the temporary production importer. A failure is a generated
manifest that does not bind every former local issue to the immutable source
commit, does not classify every active target with one category and one state
label, or cannot be regenerated byte-identically from the same source commit.
The narrow oracle is the builder's read from Git's immutable object store plus
`cmp` against a second generated copy; no production GitHub issue is created or
edited by this ticket.
